回复里的公式

块级公式 $$…$$、\[…\] 单独占行，比气泡宽时在块里横向滚动；行内公式 \(…\)、$…$ 跟着文字走。公式和正文同色，块级的极简、贴纸居中，格栅靠左。价格「$5 到 $10」、$PATH 这类不算公式。写错或画不了的公式照原文显示成等宽灰字。逐字出现时公式到了整个出来，不出半截；选中复制得到原来的 LaTeX。

用户消息左滑回溯

你发的消息整行左滑，右边让出 60dp，露出一枚回溯圆钮，不带小字，和单行气泡一样高、对着气泡竖直居中，松手过一半停住；会话在工作或等你确认时滑不动。点圆钮从底部升起面板，先引用这条消息；这一轮改过文件时选「对话和代码都回去」「只回对话」「只回代码」，没改文件就只回对话。Claude Code 面板里的两种总结不放进来。

确认后底部出一行「正在回溯…」。回对话时这条和之后的消息收起，原文填回输入框；只回代码时对话不动，弹提示条。目标机在 Claude Code 面板里对不上这条消息时退出面板，手机弹提示条并打开终端视图，让你自己选。
